# 文档索引

面向人和 Agent 的文档地图。根 [`README.md`](../README.md) 是项目介绍，[`AGENTS.md`](../AGENTS.md) 是开发约束。本目录只放设计、规范、资源与构建文档。

## 命名与维护

- 主题文档统一命名为 `NN-中文标题.md`：两位序号 + 连字符 + 中文标题，标题内不加空格。
- 序号即推荐阅读顺序；新增文档追加到末尾，不在中间插号。
- 根目录的文档只保留 `README.md` 与 `AGENTS.md`，其余文档一律放本目录；`LICENSE`、`.gitignore`、`.gitattributes` 等仓库元数据除外。
- 文档之间一律用相对链接（本目录内直接写文件名，跨目录写 `../`）。
