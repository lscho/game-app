# 03 · 视觉与交互规范

本文是游戏的视觉标准：配色、主题、层级、组件样式、动效时长与儿童可用性规则。修改任何画面、配色、布局或动画前必读；改完同步更新本文。

## 1. 视觉基调

- **关键词**：手绘绘本、奶油白卡片、糖果色、柔软阴影、圆角。避免锋利边角、纯黑、高对比刺眼配色。
- **质感**：所有面板使用「白底 + 1.5–3px 白色描边 + 低透明度暖棕阴影」，形成贴纸感。
- 阴影统一为偏暖的棕色，不使用灰色或黑色投影。
- 主要文字颜色使用暖棕色系，不使用纯黑（`#000`）。

### 2.3 游戏大厅（UVue）

- 背景使用奶油杏色纵向渐变，叠加大面积淡黄太阳、薄荷绿与粉色柔光圆；不使用游戏内的天空场景，避免与游戏页混淆。
- 品牌区：72px 圆角品牌图标 + 「欢乐游戏」27px/700 + 副标语 12px/400。
- 游戏卡：白底、32px 圆角、2px 暖色描边、暖棕柔影；整张卡片可点击。
- 封面：900×640 PNG，`aspectFill` 铺满，宽度撑满卡片内宽，高度由脚本按 `coverWidth × 640 / 900` 等比计算（约 232px @ 390 屏），不再写死高度，避免不同机型裁掉角色。
- 封面左上角标签胶囊：白底、11px/700、珊瑚粉文字；「人气游戏」用于首款，「新游戏」用于新增。
- 主操作：胶囊按钮，高 52px，白字 18px/700；底色按游戏取强调色（果园 `#FF6F8E`、泡泡 `#2AA5DA`、翻翻乐 `#E4718F`、乐队 `#E38A3F`、积木 `#3F9FD4`、坦克 `#4FA96A`、连线 `#8A72D8`）。标签胶囊使用各游戏声明的浅底色。
- 字号：大厅标题 31px/700，游戏名 21px/700，正文 12–13px；所有文案保持短句。
- 新增游戏卡片时必须同时提供 `cover`、`coverBg`（封面图未加载时的兜底色）、`accent`（按钮色）与 2–3 个 `chips`。

- 泡泡内部的 5 组渐变（白 → 糖果色 → 深色描边）定义在 `bubble.js` 的 `COLORS`，新增配色需同时保持“中心高光 + 外圈半透明”。
- 翻翻乐卡片正面的 5 组配色定义在 `memory.js` 的 `CARD_COLORS`，与图案一一对应，不使用纯色平涂。
- 乐器配色在 `band.js` 的 `INSTRUMENTS` 中，每件乐器一个主色 + 浅底，按键底色使用浅底、图标使用主色。

### 2.5 使用规则

- 新颜色优先从上述色板取；确需新增时，必须属于同一暖色/糖果色体系，并在本文登记。
- 同一元素最多使用两种阴影（一层柔影 + 一层白色描边）。
- 文字与底色的对比度按儿童可读性要求：正文 ≥ 4.5:1，大标题 ≥ 3:1；不要在浅色文字上再叠浅色。

## 3. 排版

- 字体：系统无衬线（`sans-serif`），通过 `setFont(ctx, size, weight)` 设置；不引入自定义字体。
- 字重：正文 600–700，按钮与数字 800–900。
- 字号以 CSS 像素计：

| 层级 | 字号 | 典型用途 |
| --- | --- | --- |
| 游戏开始页主标题 | 果园 `clamp(w × 0.139, 40, 58)`；新游戏 `clamp(w × 0.098, 29, 40)` | 彩虹果园四字 / 泡泡海洋四字 |
| 弹层标题 | 21–25 | 选择关卡、休息一下 |
| 庆祝标题 | `clamp(29 × s, 25, 36)` | 太棒了！ |
| 按钮 | 15–23 | 主/次按钮 |
| 正文 | 11–13 | 提示、伙伴台词 |
| 辅助 | 9.5–10.5 | 计数、页脚、关卡格 |

新游戏标题较长（4 字），`drawGameTitle()` 按字符逐字着色并旋转 ±2°，白色粗描边；`titleColors` 每款游戏一组 4 色。

- 多行文本统一用 `wrapLines(ctx, text, maxWidth)` 按字符宽度换行，不手写 `\n`。
- 数字与计数使用 `textAlign: 'right'` 靠右，标签靠左，形成稳定对齐。

## 4. 组件规范

### 4.1 主按钮 `drawPrimaryButton`

- 高度 48–66，圆角为高度的一半（胶囊）。
- 结构：底部实色 `#D66C1A`（下移 6px）→ 渐变主体 → 白色文字。
- 按下时整体下移 4px 且填充变深（`#F18B31`），不使用透明度变化。
- 开始按钮额外有一圈呼吸光晕（透明度 0.24–0.34，周期约 2.6 秒）。

### 4.2 次按钮 `drawSecondaryButton`

- 白色胶囊 + `#E3CDB2` 底部投影（下移 5px），按下下移 3px。
- 左侧可选 24px 图标位，文字居中偏右。

### 4.3 圆形图标按钮 `drawCircleButton`

- 半径 17–21，白色圆底 + 2px 白描边 + 暖棕投影。
- 图标全部用 Canvas 路径绘制（`drawPlayIcon`、`drawPauseIcon`、`drawSoundIcon`、`drawMutedIcon`、`drawHomeIcon`、`drawBackIcon`、`drawLockIcon`），不依赖字体图标。
- 顶部左侧返回钮半径 19，位于关卡芯片左侧，与芯片间距 8px；点击后弹出退出确认，不直接离开。
- 禁用时不绘制也不注册点击区域。

### 4.4 卡片 / 面板

- 圆角 20–30，外层白色描边 2–3px，底部投影偏移 4–10px。
- 内边距约 14–18；标题左对齐，关闭按钮固定在右上角。
- 庆祝与暂停卡片宽度上限 342–390，跟随 `clamp(w / 390, 0.84, 1.04)` 缩放。
- 弹窗主/次按钮垂直间距 20–22px，按钮不贴卡片底边；终章庆祝卡片底部的「关卡地图 / 游戏首页」并排按钮间距 12px。

### 4.5 HUD

- 左上：返回圆钮 + 关卡章节芯片（章节浅色底 + 图标 + 「第 N 关」），返回钮与芯片间距 8px。
- 右上：静音、暂停两个圆钮，间距 46px。
- 中部：彩虹进度条（≤12 个目标用圆点，>12 用渐变条）+ 右侧 `progress/goal`。
- 进度条下方：机制目标条（顺序队列 / 目标水果 / 收集槽 / 连击状态 / 蜜蜂提示）。新游戏的普通目标条显示 `getObjectiveText()`，左侧图标由 `drawObjectiveIcon()` 绘制。
- 目标条最大宽 300–344，居中，不覆盖安全区。
- `BaseGame` 的 HUD 总高固定为 122px（芯片 40 + 间距 8 + 进度条 36 + 间距 6 + 目标条 32），`hudBottom` 以下才是玩法区域。
- 泡泡额外在目标条下显示伙伴头像；乐队在目标条下显示节拍点；翻翻乐、积木、坦克、连线不显示额外 HUD。额外内容由 `drawExtraHud(y)` 提供，不得占用玩法区域。
- 积木、坦克、连线的场地占满屏幕中部，因此不画关卡横幅，只在 HUD 下方 `hudBottom + 14` 显示首次提示气泡；提示气泡位于场地顶部，不遮挡正在下落的积木、气球或棋盘。

### 4.6 飘字与提示

- 飘字：白描边 + 彩色填充，字号 `clamp(w × 0.064, 20, 28)`（新游戏为 `clamp(w × 0.054, 17, 23)`），上浮速度 38px/s，生命 0.95–1.15 秒。
- 顶部横幅（关卡名 + 提示）：停留 2.2–2.3 秒，出现/消失各约 0.2–0.3 秒淡入淡出，位于 `hudBottom + 8`。
- 首次提示气泡：卡通手 + 一句话，位于屏幕中部（`h × 0.5`）或 HUD 与玩法区之间（翻翻乐 `hudBottom + 18`、乐队按键上方 `padTop − 64`），首次操作后消失。提示不得遮挡需要记忆的卡片或乐器按键。
- 连击提示：果园 3 连起显示，橙色渐变胶囊，位于屏幕高度 24%；泡泡为「连戳 ×N」、乐队为「连奏 ×N」，同样在 4 连后出现，位置约 22%–42%。
- Toast（地图内）：深棕半透明胶囊，1.6 秒。

## 5. 动效

| 动效 | 时长 / 曲线 | 实现 |
| --- | --- | --- |
| 兔子跟随 | 指数平滑 `1 − e^(−11dt)` | `updatePlaying()` |
| 兔子眨眼 | 0.12 秒，间隔 3.6–6 秒 | `blinkUntil` / `nextBlinkAt` |
| 接住开心 | 0.48 秒切换 happy 图 | `happyUntil` |
| 蜜蜂眩晕 | 0.9 秒抖动 + 3 颗星光 | `dizzyUntil` |
| HUD 抖动 | 0.26–0.35 秒，`sin(t × 52) × 4px` | `hudShakeUntil` |
| 彩虹揭晓 | 1.35 秒内 `rainbowReveal` 0→1 | `updateRoundClear()` |
| 泡泡上浮 / 摆动 | 26–40px/s × 关卡 speed；正弦横向 ±5–16px | `BubbleGame.updatePlay()` |
| 泡泡破裂 | 0.35–0.7 秒粒子 + 0.45 秒点击涟漪 | `burstBubble()` / `addRipple()` |
| 翻牌 | `abs(cos(flip × π))` 缩放模拟翻转，约 0.2 秒 | `MemoryGame.updatePlay()` |
| 配对失败翻回 | 0.82 秒后翻回，期间 0.9 秒锁定点击 | `wrongBackAt` |
| 配对成功 | 12 颗花瓣/星光 + 卡片缩放 | `burstMatch()` |
| 乐器按键 | 按压缩放 + 0.17 秒发光衰减 | `padFlash` |
| 独奏回放 | 每音 0.34 秒 | `playingSolo` |
| 积木落地 / 消行 | 消除粒子 0.4–0.8 秒、整行星光 + 「+N 行」飘字 | `clearRows()` |
| 彩虹魔法清场 | 0.6 秒金色闪层 + 底部 2–4 行星光飞散 | `magicClear()` |
| 气球破裂 | 12 颗粒子 0.35–0.7 秒 + `+1` 飘字 | `burstBalloon()` |
| 坦克后坐力 | 0.25 秒内从 1 衰减到 0 | `recoil` |
| 连线消除 | 两侧各 12 颗星光 0.35–0.7 秒 + 「连上啦！」 | `burstTiles()` |
| 方块重排 | 0.8 秒闪烁提示 + 「重新排一排」Toast | `shuffleFlashAt` |
| 彩带 | 生命 2.5–6 秒，重力 120px/s² | `confetti` |
| 庆祝持续彩带 | 每 1.4 秒一批 18 片 | `addConfettiIfNeeded()` |
| 云 / 花瓣 / 萤火虫 | 极慢循环 | `updateAmbient()`、`drawAmbient()` |

规则：

- 单个交互反馈不超过 1.5 秒；庆祝动画可以是唯一例外。
- 不使用闪烁频率 > 3Hz 的效果（光敏性安全）。
- 所有动效必须能通过 `this.time` 推导，保证暂停时冻结。

## 6. 儿童可用性规则

- **点击目标**：视觉尺寸 ≥ 34px，命中区域再外扩 4–8px（泡泡为 14px）；主要按钮高度 ≥ 48px。卡片、乐器按键、积木/坦克的圆形操作钮本身即命中区（圆钮额外外扩 6px）。
- **文字量**：按钮 ≤ 6 字，提示 ≤ 12 字；不依赖阅读完成操作。
- **颜色不单独承载信息**：顺序、目标、收集均同时用图标与文字表达；泡泡的带刺状态除红色描边外还有尖刺造型，翻翻乐配对成功除音效外还有飘字与粒子，连线的方块图案与颜色一一绑定。
- **无失败惩罚**：不出现红色叉号大图标、不出现「失败」字样、不播放负面音效以外的惩罚。翻错牌、敲错乐器、戳到带刺泡泡、连不上方块、积木堆到顶都只给提示。
- **正向措辞**：失误文案用「先接苹果」「先敲小鼓」「这个有刺哦」「换一对试试」，不用「错误」「失败」「你输了」。
- **一致性**：静音图标在开始页、HUD、暂停页三处状态必须同步；返回键行为在各界面保持一致；七款游戏共享同一静音状态。
- **安全区**：所有顶部/底部元素必须避开刘海与手势条；当前通过 `safeTop` / `safeBottom` 实现。

## 7. 新增视觉元素的检查清单

- [ ] 颜色取自本文色板，或已登记新色。
- [ ] 使用 `fillRound` / `strokeRound` / `drawLabel` 等现有工具，不重复实现圆角与文字。
- [ ] `ctx.save()/restore()` 成对，`globalAlpha`、`textAlign` 已恢复。
- [ ] 尺寸使用 `clamp` 跟随屏宽，未硬编码超过 390 的宽度。
- [ ] 按钮命中区已注册，且在弹层末尾做了 `buttons` 过滤。
- [ ] 动效时长与曲线符合本文表格。
- [ ] 在刘海屏与 16:9 屏各验证一次。
