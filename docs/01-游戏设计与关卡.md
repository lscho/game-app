# 01 · 游戏设计与关卡

本文描述七款游戏的面向对象、核心循环、玩法机制、关卡数值与成长系统。第 1–9 节为《小兔子的彩虹果园》（`game/orchard.js`），第 10–15 节为共用 `game/engine.js` 的六款新游戏。改动玩法或难度前必须先读本文，改完后同步更新。通用外壳与新增游戏流程见 [06-多游戏架构与新增游戏指南.md](06-多游戏架构与新增游戏指南.md)。

## 1. 目标与设计原则

| 项目 | 彩虹果园 | 泡泡海洋 / 翻翻乐 / 小小乐队 / 积木拼图 / 坦克打气球 / 连线小方块 |
| --- | --- | --- |
| 目标玩家 | 4–7 岁儿童，能独立完成「拖动」一个手势 | 4–9 岁儿童，能完成点击与「点两张牌」 |
| 单局时长 | 每关 40–90 秒，20 关合计约 30 分钟 | 每关 30–80 秒，16 关合计约 20 分钟 |
| 操作 | 单指左右拖动；所有按钮为点击，无长按、无双击、无多点触控 | 单指点击；翻翻乐连续点两张、连线可点两次或拖动，积木与坦克按住左右按钮移动 |
| 失败条件 | **无**。失误只清空连击并给出温和提示 | **无**。失误只给提示，不扣进度、不结束 |
| 付费与广告 | 无广告、无内购、无网络请求，可完全离线 | 同上 |
| 文字量 | 单句不超过 12 个汉字；主要信息用图标和颜色表达 | 同上，按钮 ≤ 6 字、提示 ≤ 12 字 |

设计上刻意回避了传统街机要素：没有倒计时、没有生命值、没有分数排名。正向反馈来自进度条、粒子/礼花、音效与伙伴出场。

新游戏的通关反馈统一为：进度条填满 → 短暂庆祝动画 → 庆祝卡片（伙伴 + 语音）→「继续探险」。详见 [06](06-多游戏架构与新增游戏指南.md)。

## 2. 核心循环（彩虹果园）

```
开始界面（开始采摘 / 继续第 N 关）
   ↓
关口横幅（第 N 关 · 关卡名 + 一句提示，2.3 秒）
   ↓
接水果 ──→ 进度 +1 ──→ 连击 +1、音效升级、粒子/飘字
   │                    ↓
   └→ 失误：清空连击 + 提示，进度不变
                        ↓
              progress ≥ goal → 彩虹全屏揭晓（1.35 秒）
                        ↓
              庆祝卡片（伙伴出场、接住数量、音效/语音）
                        ↓
        「继续探险」下一关 ／「关卡地图」／「回到首页」
```

- 进入关卡有 1 秒的 `startGrace`，期间不生成水果，给孩子反应时间。
- 生成间隔会随进度略微缩短：`spawn × (1 − progress/goal × 0.12)`，并叠加 ±12% 随机，最终夹在 0.48–1.3 秒。
- 每次掉落持续时间由 `speed`（占屏高比例/秒）决定，数值越大越快。

## 3. 玩法机制

机制由关卡配置的 `mechanic` 字段决定，共 7 种：

| mechanic | 界面标签 | 规则 | 失误判定 |
| --- | --- | --- | --- |
| `classic` | 采摘 | 接住任意水果；星星果计 2 分 | 无（漏接只清连击） |
| `target` | 目标 | 只接指定水果；可配置每接 N 个切换目标 | 接到非目标水果 |
| `order` | 顺序 | 按 HUD 顶部的顺序依次接；每接对一个，队列前进一格；**其他正在下落的水果继续下落，不清屏** | 接到非当前队首水果 |
| `avoid` | 躲蜂 | 接水果的同时躲开蜜蜂 | 接到蜜蜂（眩晕 0.9 秒 + 清连击） |
| `combo` | 连击 | 在 `comboWindow` 秒内连续接住，达成目标连击数 | 超时或接错即断连击 |
| `collect` | 收集 | 本轮集齐 6 种水果；可多轮（目标 12 = 两轮） | 重复接本轮已收集的水果 |
| `star` | 星星 | 只接星星果 | 接到普通水果 |

机制实现位置：

- 水果选择：`chooseFruitKey()` — 各机制决定目标水果出现概率，其余为干扰水果。
- 接住判定：`collectFruit()` — 先做机制校验，通过后累计进度并播放反馈。
- 失误反馈：`wrongCatch()` / `hitBee()`；漏接反馈：`missFruit()`。
- HUD 目标条：`drawObjective()` 按机制分发到 7 个 `drawXxxObjective()`。

### 3.1 干扰与防挫败

- `order`：当前需要的队首水果出现率约 76%，其余为干扰项；接到正确水果后，屏幕上同类水果会用星光特效清除，避免「接不完」。
- `target`：目标水果出现率 52%–55%；目标轮换时会清除旧目标的水果并弹出「新目标：X」。
- `collect`：未收集的水果出现率 70%；集齐 6 种后立即开启下一轮并撒礼花。
- `star`：星星果出现率 48%–52%，其余为干扰。
- 蜜蜂：场上最多 2 只；每关开始 1.6 秒内不生成蜜蜂。

## 6. 计分与反馈

游戏不使用总分，进度条即唯一目标。内部保留 `totalCaught`（本次会话接住总数）、`caughtInLevel`（本关接住数）、`bestCombo`（最佳连击）。

| 事件 | 表现 |
| --- | --- |
| 接住水果 | 粒子 13 个 + 飘字 `+1`；星星果 20 个粒子 + 彩带 22 片 + `+2` |
| 连击 | 连续接住间隔 ≤ `comboWindow`（默认 2.2 秒，连击关 2.6 秒）时递增；≥3 连时 HUD 上方弹出「连击 ×N」 |
| 接错 / 接蜜蜂 | 音效 `miss`，HUD 抖动，飘字提示（如「先接苹果」「只接橙子和葡萄」）；蜜蜂额外眩晕 0.9 秒 |
| 漏接 | 地面水花 + `miss` 音效 + 清连击；若是顺序关的队首水果，飘字提醒「要接 X」 |
| 过关 | 彩虹从底部升起，1.35 秒后进入庆祝卡片 |

进度写入后立即夹取：`progress = min(goal, progress)`，因此任何机制都不会超目标。

## 7. 解锁与成长

- 完成第 N 关后：`completedLevels.add(N)`，且 `maxUnlocked = max(maxUnlocked, min(20, N+1))`，立即写入存档。
- 关卡地图：5 行（章节）× 4 列；已通关显示勾选与章节色，当前可玩关显示 `NEW` 脉冲边框，未解锁显示灰色与锁图标。
- 开始按钮文案：未玩过 →「开始采摘」；有进度 →「继续第 N 关」；全通关 →「再玩一次」。
- 伙伴解锁（按关卡区间，通关该区间任意一关即触发）：
  - 通关第 1–7 关 → 小松鼠
  - 通关第 8–14 关 → 小刺猬
  - 通关第 15–19 关 → 小鸟
  - 通关第 20 关（彩虹终章）→ 一次性补齐三位，并播放 `final` 语音
- 伙伴只影响庆祝卡片文案与开始页「我的果园伙伴」货架，不改变玩法。

## 8. 音频与语音触发

| 场景 | 音频 |
| --- | --- |
| 全局 | `bgm.mp3` 循环，音量 0.3 |
| 接住 | `catch-1` … `catch-6` 按当前连击档位切换（1→6，超过 6 固定 `catch-6`） |
| 星星果 | `star`；过关 | `celebrate` + `level` |
| 按钮/切图 | `ui`；暂停 / 恢复 | `pause` / `resume` |
| 失误 / 漏接 / 蜜蜂 | `miss` |
| 伙伴出场 | `friend`，并解锁对应语音 |
| 语音 | 开始 `start`、重玩 `replay`、终章 `final`、第 1–2 关按接住数 `celebrate-{1|2}-{6..12}` |

语音只有一路播放通道：新语音开始前会停止上一条，切换界面也会停止。完整清单见 [04-资源与音频清单.md](04-资源与音频清单.md)。

## 9. 调参与验收建议

- 调难度优先动 `speed` 与 `spawn`，其次 `maxFruits`；不要轻易增加 `goal`，单关时长会明显变长。
- 同一章内速度递增不超过约 0.03，跨机制切换的关卡（11、12、18）应保留一点缓冲。
- 新增机制必须同时给出：HUD 目标条画法、失误文案、`chooseFruitKey()` 的出现率策略、至少一关的数值配置。
- 验收标准：目标年龄儿童在无人指导下能完成第 1 关；单关失败重试次数不应影响心态（没有失败态是产品底线）。

## 10. 泡泡海洋（`game/bubble.js`）

### 10.1 玩法

海水里不断浮起泡泡，戳破任意普通泡泡即 +1。泡泡里偶尔藏着海洋朋友（鱼、蟹、海星、水母、贝壳、章鱼），戳中朋友泡泡会把它加入本关的伙伴栏，并播放 `friend` 音效与礼花。

| 元素 | 规则 |
| --- | --- |
| 普通泡泡 | +1，播放 `pop`；每连戳 4 个换 `star` 音效 |
| 闪亮泡泡 | 约 14% 概率出现，+2，粒子更多 |
| 带刺泡泡 | 只出现在第 10、12、14–16 关；戳到扣 0 进度，播放 `nope`，提示「这个有刺哦」 |
| 朋友泡泡 | 每关需要 `friends` 位（1–4），按 `popsUntilFriend` 间隔放出；同一屏最多一个 |
| 漏接 | 泡泡浮出屏幕顶部，不惩罚，只加快下一次生成 |

- 泡泡从屏幕底部生成，以 `speed`（每秒上升占屏高比例，0.55–1.3）上浮，并做正弦横向摆动。
- 点击命中半径为 `r + 14`，带刺泡泡同样参与命中，避免「点空」。
- 连戳间隔 ≤ 2.4 秒累计连击，连击只影响音效与「连戳 ×N」浮层，不影响得分。
- 目标达成（`progress ≥ goal`）后 0.3 秒进入过关流程，剩余泡泡继续上浮并淡出。
- 每关开始 3 个初始泡泡分布在屏幕中部，避免开局空屏。

## 11. 动物翻翻乐（`game/memory.js`）

### 11.1 玩法

卡片背面朝上铺在屏幕上，点开两张，图案相同则配对成功并保持翻开；不同则两张自动翻回。全部配对完成即过关。

| 元素 | 规则 |
| --- | --- |
| 开场预览 | 每关开始所有卡片正面展示 1.6 秒，方便记忆；首次点击可提前结束预览 |
| 翻牌 | 播放 `flip`；第一张额外播放 `pick` |
| 配对成功 | `match` 音效 + 花瓣/星光 + 「找到啦！」飘字，卡片保持翻开并缩放一下 |
| 配对失败 | `nope` 音效 + 卡片轻微抖动，0.82 秒后翻回；期间 0.9 秒内不接受新点击 |
| 全部完成 | 播放 `star` 与 40 片彩带，0.5 秒后进入过关流程 |

- 翻错不扣任何东西，也不计入失败；`flips` 只作为庆祝卡片的统计。

### 14.1 玩法

小坦克沿草地左右开，彩色气球从天空飘下来。按住左右圆钮移动坦克，点中间圆钮开炮，打中气球即可推进。气球飘到地面只是轻轻散开，稍后会有新的气球飘下来，气球永远打不完，也不会失败。

| 元素 | 规则 |
| --- | --- |
| 移动 | 按住左右圆钮持续移动，按下当帧先走一小步；速度 `clamp(w × 0.85, 240, 380) × moveSpeed` |

| 闪亮气球 | 第 11 关起出现（约 28%），要打两下；第一下播放 `hit` 与「再来一下」飘字 |

## 15. 连线小方块（`game/lines.js`）

### 15.1 玩法

场上铺满糖果色小方块，每种图案成对出现。点两个图案相同、且能用不超过两个转弯的空路线连起来的小方块，就能把它们连走。连完所有对子即过关。

| --- | --- |

### 15.3 场景与伙伴

- 场景为四章天空 + 云 + 草地 + 小花；花园章的天空换成薄荷色，星空章变暗并出现闪烁小星。
- 主持伙伴是小企鹅，站在草地右侧轻轻浮动。
- 方块使用浅色填面 + 深色描边 + 白色符号 + 左上高光；选中时描边变白、整体抬起 3px 并放大 4%。

### 15.4 语音与音效

- 音效键：`connect`（选中方块）、`done`（连成一对）、`star`、`nope`、`level`、`celebrate`、`friend`、`ui`、`pause`、`resume`。
- 语音同上：`start` / `clear` / `great` / `final` / `replay`。

### 15.5 调试

`findAnyPair()` 返回一对当前可连的方块；`tryConnect(a, b)` 直接尝试连线；`debugState()` 继承基类字段，可用 `progress` / `goal` 观察连对进度。`window.__kidsGame` 仍由 `BaseGame` 挂载。
